# Example Skill (Template)

## When to Use

- Use this structure when writing a new domain skill.
- Do not activate this template for real user tasks.

## Core Principles

1. Prefer actionable checklists over theory dumps.
2. Separate facts from opinions; note confidence.
3. Encode anti-patterns seniors actually avoid.

## Step-by-step Workflow

1. Clarify the goal and constraints.
2. Apply the domain decision framework.
3. Validate against the quality bar.
4. Report risks and next actions.

## Anti-patterns

- Vague advice without steps
- Ignoring edge cases
- Overwriting skills without version bump

## Quality Bar / Definition of Done

- [ ] Clear when-to-use
- [ ] Ordered workflow
- [ ] At least one concrete example
- [ ] Sources or confidence notes
